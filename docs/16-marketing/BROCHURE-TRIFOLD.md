## Print notes

1. Open the print HTML in Chrome → **Print** → Save as PDF → enable **Background graphics**.
2. Page size: **A4 landscape**, margins **None**.
3. For commercial press: convert PDF to **CMYK**, add **3 mm bleed**, keep text inside the **7 mm** safe area (already applied in layout). Fold marks are screen-only and hidden in print.
