# Definition of Ready (DoR)

| Document ID | GOV-DOR-001 |
| Status | DRAFT |

A feature enters a Sprint **only when ALL** are true:

- [ ] Business requirement document exists (feature 01)
- [ ] User stories + acceptance criteria exist (feature 02)
- [ ] Functional requirements exist (feature 03)
- [ ] Business workflow documented (feature 04)
- [ ] UX requirements for applicable surfaces (feature 05)
- [ ] Architecture design approved (feature 06)
- [ ] Database design + migration number assigned (feature 07)
- [ ] API contract documented (feature 08)
- [ ] RBAC permissions defined (feature 09)
- [ ] Audit requirements defined (feature 10)
- [ ] Testing strategy defined (feature 11)
- [ ] Migration + rollback plan (feature 12)
- [ ] Dependencies identified and satisfied or scheduled
- [ ] Risks logged in [risk register](../13-project-management/risk-register.md)
- [ ] **DECISION REQUIRED** items resolved or explicitly waived by PO
- [ ] Feature status = **APPROVED** on [feature board](../13-project-management/feature-status-board.md)
- [ ] Sprint goal includes feature with capacity allocated
