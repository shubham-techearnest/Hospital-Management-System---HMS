# P2-F2-02 — User Stories

## US-OPD-002 — Skip queue token

**As a** Receptionist, **I want to** skip a waiting or called patient, **so that** I can serve the next patient without cancelling the visit.

## US-OPD-003 — Recall skipped token

**As a** Receptionist, **I want to** recall a skipped patient, **so that** they return to the called state with elevated priority.
